### ⚡ Harpia

A theoretical programming language based on the idea of dividing the processor into different parts to execute operations.

The syntax looks like someone had an epileptic seizure while writing assembly.

The actual goal is to explore alternative approaches to computation and processor organization.

**Status:** Theoretical / Experimental.
